# 简历项目计划：MotionCore 工业三轴运动控制与数字孪生仿真平台

## 项目定位

项目名称确定为 **MotionCore：基于 C++ 的工业三轴运动控制与数字孪生仿真平台**。

它服务于三个目标岗位：机器人 C++ 软件、半导体设备软件、自动化软件。项目不依赖真实设备，先用确定性数学模型搭建虚拟电机和 XYZ 运动平台，把控制算法、实时循环、日志、测试和故障场景做成可以反复运行的软件，再接入 Qt 和更真实的设备接口。

## 为什么从单轴离散仿真开始

单轴位置/速度/加速度闭环很小，但它包含工业运动控制项目最重要的工程闭环：

```text
目标值 -> 控制器 -> 被控对象 -> 状态测量 -> 误差 -> 日志与指标
```

当前代码已经实现了这一闭环。后续的 PID 伺服、S 曲线规划和三轴协调，都只是把状态、模型和控制器逐步扩展，而不是推倒重来。

## 里程碑

### M0：单轴离散仿真与基本闭环（当前）

- 位置、速度、加速度状态和离散积分；
- 基本位置/速度闭环、速度和加速度限幅；
- CSV 日志和 CTest 单元测试；
- 验收：构建成功、测试通过、100 mm 阶跃最终误差小于 0.5 mm。

### M1：电机建模与 PID 伺服控制

- 建立简化电机动力学模型；
- 加入位置环、速度环、PID 和积分抗饱和；
- 统计上升时间、超调量、稳态误差和控制周期。

### M2：工业轨迹规划算法

- 梯形速度规划、加减速控制和七段 S 曲线；
- 统计速度、加速度和加加速度约束；
- 规划结果交给伺服控制器执行。

### M3：三轴协调运动控制

- XYZ 三轴状态和同步插补；
- 直线插补、圆弧插补和运动边界约束；
- 统计三轴同步误差和轨迹误差。

### M4：工业软件架构

- 运动状态机、回零、软限位、故障注入和急停逻辑；
- CSV 日志、参数管理、CMake 构建、Git 版本管理和自动化测试；
- 控制、仿真和日志线程。

### M5：Qt 可视化与项目验收

- Qt 上位机显示电机位置、速度曲线和 XYZ 轨迹；
- 参数设置、启动/停止、故障显示和数据回放；
- 整理架构图、运行截图、测试结果和简历项目描述。

## 简历上最终要能说清楚的指标

- 控制周期和周期抖动；
- 位置/轨迹误差 RMSE、最大误差、稳态时间；
- 噪声、延迟、饱和场景下的退化程度；
- 单元测试和回归测试数量；
- PID、轨迹规划算法的效果对比；
- 每项指标对应的实验命令、CSV 日志和图表。

## 当前学习节奏

默认按每天 1–2 小时推进：先读懂当前 M0，再做一个小改动、运行测试、观察日志、记录结论。每个里程碑都要留下可运行代码、实验数据和一段项目说明，避免只积累零散知识点。
