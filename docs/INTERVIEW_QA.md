# 技术面试问答

以下问题均以仓库现有实现为背景；回答中的类名可直接在 `include/`、`src/`、`gui/` 和 `tests/` 中查阅。

1. **项目解决什么问题？**  用可复现软件仿真验证单轴到三轴运动控制算法，并组织成可测试的 C++ 控制软件架构。
2. **为什么内部使用 SI 单位？**  质量、力和时间公式自然使用 SI，可避免 mm 与 m 混用；显示层再转换。
3. **动力学方程是什么？**  `m dv/dt=F_drive-bv-F_load`，`dx/dt=v`，由 `DynamicAxisModel` 离散更新。
4. **离散位置如何计算？**  `x_next=x+v dt+0.5 a dt²`，速度为 `v+a dt`。
5. **目标速度是否直接写入实际速度？**  不会；目标经过串级控制器，实际速度只由模型更新。
6. **P 控制的缺点？**  有稳态误差，尤其存在持续负载时；提高增益又会增加饱和和振荡风险。
7. **PI 如何消除稳态误差？**  积分累积持续误差产生补偿，条件积分和积分限幅防止 wind-up。
8. **PID 微分为什么对测量值？**  对测量值求导避免设定值阶跃产生微分冲击，并用滤波抑制噪声。
9. **串级控制为什么分位置环和速度环？**  位置环给慢变量速度目标，速度环快速控制力，便于限制速度和加速度。
10. **阻尼前馈是什么？**  近似加入 `b*v_ref` 的力，减少速度变化时的稳态控制负担；仍经过模型。
11. **梯形何时退化为三角形？**  当距离不足以达到 `V²/A` 时，峰值速度为 `sqrt(D A)`。
12. **S 曲线解决什么问题？**  用有限 Jerk 平滑加速度变化，减少机械冲击。
13. **S 曲线短距离怎么处理？**  先移除匀速段，再移除恒加速度段，极短距离使用四段 Jerk 轨迹。
14. **为什么终点可以精确？**  各段使用解析公式采样，并在终点按轨迹定义返回目标位置/零速度，避免积分累计误差。
15. **直线插补如何同步三轴？**  只规划一个标量路径长度，三轴通过同一个 `s(t)` 和方向向量映射。
16. **圆弧的向心加速度是什么？**  `v²/R`，合成加速度是切向和径向分量的向量合成。
17. **圆弧为什么不能只检查切向加速度？**  曲率会引入向心加速度和额外 Jerk，必须检查合成量。
18. **多段拐角如何处理？**  本项目采用拐角速度归零后切换，暂不做前瞻和连续曲率过渡。
19. **状态机有什么价值？**  把 Enable、Home、Running、Fault 等合法转移集中管理，拒绝非法调用。
20. **命令队列如何避免重复执行？**  只有 `Queued` 可进入 `Running`；Canceled/Rejected/Completed 是终态。
21. **急停和 Stop 有何区别？**  Stop 生成受控减速；EmergencyStop 清理/取消命令并锁存状态，机械轴仍可惯性滑行。
22. **回零为什么不能直接把位置写成零？**  真实系统需要传感器触发和运动过程；直接赋值会破坏动力学连续性。
23. **软件限位如何预测风险？**  用速度、制动能力和安全余量估计 `d_stop=v²/(2a_brake)`，并持续检查实际位置。
24. **Fault 时应如何处理物理轴？**  禁止新控制命令，但驱动力策略必须明确；惯性和阻尼仍由动力学模型计算。
25. **CSV 中参考和实际为什么分开？**  参考是规划器输出，实际是闭环模型响应；分开才能计算真实跟踪误差。
26. **Qt 为什么要用 worker 线程？**  仿真循环不应阻塞 GUI；worker 用 1 ms 内部步长，GUI 只接收快照。
27. **Qt 信号槽如何保证线程边界？**  GUI 到 worker 使用 queued connection，worker 返回不可变 `GuiSnapshot`。
28. **offscreen 测试能证明什么？**  能证明 Qt 对象、信号槽和控制器数据连接可运行；不能证明人工视觉体验或硬实时。
29. **CMake 如何隔离 Qt？**  `MOTIONCORE_BUILD_GUI` 默认 OFF，核心目标不链接 Qt；开启时才 `find_package(Qt6 Widgets Test)`。
30. **CTest 为什么比只运行程序好？**  每项测试有真实数值断言，覆盖公式、边界、故障和 CSV，而不是仅检查返回码。
31. **ASan/UBSan 的作用？**  查找越界、悬空访问和未定义行为；它们不能替代数学正确性测试。
32. **如何验证测试不是自证？**  期望时间和几何值由独立公式写在测试中，不从被测对象复制答案。
33. **为何不直接把 Qt GUI 做成另一套控制器？**  会产生逻辑分叉；UI 只调用核心 `MotionController`，保证同一套权限和故障规则。
34. **项目目前最大的限制？**  无真实硬件/实时验证，GUI 是 XY 投影而非三维渲染；CSV 离线回放已实现基础校验和只读播放，但没有完整三维视图。
35. **如果继续工程化，下一步是什么？**  在不改变数学内核的前提下补齐用户验收、Qt 图形交互和硬件抽象层，并进行独立安全评审。
