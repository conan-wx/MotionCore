# 数学模型与公式

本文给出项目中使用的主要公式、单位和适用条件。内部统一采用 SI：位置 m、速度 m/s、加速度 m/s²、Jerk m/s³、质量 kg、力 N；CLI/CSV 的显示单位按字段名换算为 mm 系列。

## 机械轴

等效一维模型为

`m dv/dt = F_drive - b v - F_load`, `dx/dt = v`。

在一个固定步长 `dt` 内使用当前状态的常加速度积分：

`a[k] = (F_drive[k] - b v[k] - F_load[k]) / m`

`x[k+1] = x[k] + v[k]dt + 0.5 a[k]dt²`

`v[k+1] = v[k] + a[k]dt`。

`m>0`、`dt>0` 且所有输入有限时公式有效。驱动力在进入模型前限制到配置的对称范围，不能将参考速度直接写入实际速度。

## P、PI、PID 与串级控制

位置环通常为 `v_cmd = clamp(Kp_x (x_ref-x), ±v_max)`，然后限制速度指令变化率。速度 PI 为 `F = Kp_v e_v + Ki ∫e_v dt`，在输出饱和且误差仍推动饱和方向时暂停积分，避免 wind-up。PID 的微分项对测量值求导并滤波，从而避免设定值突变带来的 derivative kick；`reset()` 清除积分和历史样本。

阻尼前馈可写为 `F_ff=b v_ref`。它只改变驱动力指令，不能绕过动力学模型。

## 梯形/三角形规划

对位移 `D=|x1-x0|`、速度约束 `V`、加速度约束 `A`：若 `D >= V²/A`，加速时间 `t_a=V/A`，匀速时间 `t_c=(D-V²/A)/V`，总时间 `2t_a+t_c`。否则峰值速度 `V_p=sqrt(D A)`，总时间 `2V_p/A`，形成三角形。位移方向由 `sign(x1-x0)` 乘到位置、速度和加速度上。各段使用解析运动学公式，终点显式返回目标位置和零速度。

梯形加速度切换不连续，理论 Jerk 为冲激，CSV 中用明确的 NaN/适用性标记，不把它伪装成有限 Jerk 轨迹。

## 七段 S 曲线

完整轨迹依次包括正 Jerk、恒正加速度、负 Jerk、匀速、负 Jerk、恒负加速度、正 Jerk。Jerk 段时间通常为 `t_j=A/J`；若达不到 `A`，退化为无恒加速度的 Jerk 段；若达不到 `V`，再消除匀速段；极短距离可退化为四段 Jerk 轨迹。每段以解析积分计算 `x,v,a`，边界采用双精度和浮点容差，终点强制由轨迹定义返回精确目标值而不是累计积分结果。

## 三轴直线插补

`L=||P1-P0||`，单位方向 `u=(P1-P0)/L`。标量路径 `s(t),v(t),a(t),j(t)` 由 Phase 3 规划器生成：

`P=P0+u s`, `V=u v`, `A=u a`, `J=u j`。

零长度时直接返回同一点的零状态。三轴共用一个 `s(t)`，因此不能由三个独立单轴规划器拼接。

## XY 圆弧

圆心 `C`、半径 `R=||P0-C||`，参数方程为 `P=(cx+R cos θ, cy+R sin θ,z0)`。弧长 `L=R|Δθ|`，再将标量 `s` 转成角度。切向单位向量 `T` 和圆心指向轨迹点的径向单位向量 `N` 给出

`A=a_t T-(v²/R)N`

`J=(j_t-v³/R²)T-(3v a_t/R)N`。

因此只满足切向加速度并不等于满足三维合成加速度；实现需检查 `||A||` 和 `||J||`。有限圆弧必须检查角度范围内的极值点，而非只看端点。

## 跟踪指标与停止距离

三维位置误差 `e=P_actual-P_ref`，RMSE 为 `sqrt(mean(||e||²))`。直线横向偏差是实际点到有限直线的垂直距离；圆弧径向误差是 `abs(||P_xy-C||-R)`，有限弧最近距离还要考虑端点。

预测制动距离近似为 `d_stop=v²/(2 a_brake)`，实际监控可加一个 `|v|dt` 更新延迟项和安全余量。`a_brake` 必须来自质量、阻尼、负载和最大可用驱动力，不能只配置一个任意大的数。
